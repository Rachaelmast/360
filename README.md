# SkyBridge 360 Review

360-degree feedback for SkyBridge Healthcare staff: Recruiter, Account Manager, Director, and Executive VP of Operations.

- **Give feedback**: reviewers pick an open review and their relationship (Self, Manager, Peer, Direct report, Cross-functional partner), rate each statement from 1 to 5 or N/A, and answer three open questions.
- **Review cycles** (editors/owner): open, close, or delete a review for an employee and period.
- **Results** (editors/owner): competency scores comparing others with self, blind spots, hidden strengths, a breakdown by relationship, comments, and a CSV export. A sample report shows how a finished one looks.
- **Question bank**: every statement for each title.

Open `index.html` in a browser to use it locally. Locally, data stays in that browser only.
